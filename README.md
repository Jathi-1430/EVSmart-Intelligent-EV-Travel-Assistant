# EVSmart — Intelligent EV Travel Assistant

## Current Version
A beginner-friendly Flask prototype containing:
- Home dashboard
- EV trip/range calculator
- Charging-station demo interface
- Battery health estimator
- Low-battery emergency assistant

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal.
3. Create a virtual environment:
   `python -m venv venv`
4. Activate it on Windows:
   `venv\Scripts\activate`
5. Install dependencies:
   `pip install -r requirements.txt`
6. Start:
   `python app.py`
7. Open the local address shown by Flask, usually:
   `http://127.0.0.1:5000`
